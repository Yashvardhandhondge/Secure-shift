Guidelines
  • Application name: 3-60 characters, unique inside the enterprise.
  • Framework version: e.g. "Java 8" - support status tells if the vendor still supports it.
  • Age 0-60, security issues 0-999, compliance policies 0-10, lines of code 100 or more.
  • Downtime tolerance Low means the business cannot accept downtime.
  • Components (services, databases, APIs) are added on the Dependencies tab.
