How points are calculated
  • Dependency Points = Type Weight × Criticality Points
  • Type weight: Application 4 · Service 3 · Database 3 · API 2
  • Criticality: Low 1 · Medium 2 · High 3 · Critical 4
  • Raw points = sum of all outgoing links
  • Dependency Impact = 100 × (1 − e−raw/20) → 0-100 with diminishing returns
